# Civiewer

Read-only overview of GitHub Actions and Forgejo Actions.

## Register

product

## Users and purpose

A homelab owner checks CI across organizations and repositories from a desktop
or phone. Success means recognizing the latest state, inspecting a recent run
sample, and opening the exact provider run quickly.

## Principles

- One workflow per row, with compact identity and broad horizontal history.
- Show real status, timing and coverage. Missing timing stays unavailable.
- Preserve useful rows during outages and explain stale or partial data.
- Keep configuration and credentials on the Go server.
- Search and filters survive refresh and browser navigation.
- The providers own logs and run actions; Civiewer links to them.
